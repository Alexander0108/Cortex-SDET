# 📋 Examples

This directory contains **example outputs** generated by Cortex-SDET, demonstrating the tool's capabilities.

## 📁 Files

| File                   | Description                                                                                      |
| ---------------------- | ------------------------------------------------------------------------------------------------ |
| `test_login_test.py`   | A basic AI-generated Playwright test for the-internet.herokuapp.com/login                        |
| `test_login_test.md`   | Test report showing status, model, and execution details                                         |
| `test_healing_demo.py` | A self-healed test — originally had a broken selector `#palyanytsya`, AI fixed it to `#username` |
| `test_healing_demo.md` | Detailed report of the self-healing process with AI diagnosis                                    |

## ⚡ Key Features Demonstrated

- **AI-powered test generation** from natural language requirements
- **Self-healing mechanism** — automatically fixes broken selectors
- **Detailed reporting** — MD reports with AI diagnosis

> **Note:** These are static examples. Real tests are generated in `generated_tests/` during runtime.
